# YouTube AI v3 Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the panel UI on branch `v2` to match the Claude Design handoff in `docs/design/v3-handoff/`, adding the features it depends on (OpenRouter, chapters, key validation, structured summary, usage counters, settings, shortcuts, export).

**Architecture:** The v2 skeleton stays: content script in a shadow root, LLM calls in the background streamed over a port, pure logic in `src/lib` with Vitest. The UI layer (`src/components`) is rewritten around the handoff: a shell with header, chapter bar, tab row, views (`main | settings | onboarding`), and three panels. Summary becomes structured (lead / moments / notes / plain / questions) by asking the model for a fixed Markdown shape and parsing it progressively. New cross-cutting state lives in small React contexts (toast, navigation, chat draft, summary).

**Tech Stack:** wxt 0.21, React 19, TypeScript strict, Tailwind v4, shadcn (radix-ui), `@phosphor-icons/react`, ai 7.x, `@ai-sdk/react`, `@ai-sdk/{openai,anthropic,google}`, `@openrouter/ai-sdk-provider`, Streamdown, Biome 2, Vitest 5 (jsdom), pnpm.

**Spec:** `docs/superpowers/specs/2026-10-26-v3-redesign-design.md` (reads with `docs/design/v3-handoff/README.md` and `docs/design/v3-handoff/prototype/extracted/{logic.js,template.html}` for exact copy, numbers and sample data).

## Review Focus

1. Summary text that does not follow the requested shape (missing headings, `**m:ss**` or `[m:ss]` bullets, headings cut mid-word while streaming): the panel must still render what it has and never throw. Pinned in Task 5 (`parseSummary` tolerance tests).
2. Watch pages with no chapters, or chapters whose first entry is not `0:00`, or description timestamps only: the chapter bar must render one or more segments covering the whole duration and never divide by zero. Pinned in Task 4 (`parseChapters*`, `chapterSegments`).
3. Settings written by the v2 build (no `theme`, `textSize`, …, no `models.openrouter`): the panel must boot with defaults filled in, not crash on `undefined`. Pinned in Task 2 (`mergeSettings`).
4. A wrong OpenRouter key: `/models` answers 200 for any key, so validation must use `/auth/key` and report "rejected (401)". Pinned in Task 3.
5. macOS turns `Alt+S` into `e.key === "ß"`: shortcuts must match on `e.code`, and must not fire while typing in the composer or YouTube's search box. Pinned in Task 13.
