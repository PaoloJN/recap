# YouTube AI Extension v2 Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 2023 Plasmo extension with a WXT + React 19 extension that injects a Summary / Transcript / Chat panel into the YouTube watch page, streaming from OpenAI, Anthropic or Google with the user's own key.

**Architecture:** One content script mounts a React app in a shadow root at the top of YouTube's sidebar; it fetches the watch page and transcript itself. All LLM calls run in the background service worker and stream back over a `runtime.connect` port as AI SDK `UIMessageChunk`s; the content script wraps that port in a custom `ChatTransport` so `useChat` and the summary view share one streaming path. Pure logic (parsing, prompts, timestamps, storage pruning) lives in `src/lib` and is unit tested; UI is shadcn + AI Elements.

**Tech Stack:** wxt 0.21 + @wxt-dev/module-react, React 19, TypeScript strict, Tailwind v4 (@tailwindcss/vite), shadcn CLI 4.x, AI Elements, ai 7.x, @ai-sdk/react, @ai-sdk/openai, @ai-sdk/anthropic, @ai-sdk/google, Biome 2.x, Vitest 5 + wxt/testing, pnpm.

**Spec:** `docs/superpowers/specs/2026-10-25-v2-rebuild-design.md`

## Global Constraints

- Work on branch `v2`. Tag the pre-rebuild tree `v1-legacy` before deleting old source. Merge to `main` only in the final task.
- Delete all old source in the first commit of the rebuild: `components/`, `contexts/`, `lib/`, `utils/`, `src/`, `tailwind.config.js`, `postcss.config.js`, `components.json`, `.prettierrc.mjs`, `pnpm-lock.yaml`. Keep `LICENSE`, `assets/icon.png`, `docs/`, `.gitignore`, `.vscode/`.
- Package `version` and manifest version: `2.0.0`. `name`: `youtube-ai`, `displayName`/manifest name: `YouTube AI`.
- Content script matches `*://www.youtube.com/*` only. Manifest permissions: `storage`. Host permissions: `https://api.openai.com/*`, `https://api.anthropic.com/*`, `https://generativelanguage.googleapis.com/*`.
- LLM calls only in the background. API keys are never logged and never put in a URL.
- No `console.log` left in committed code; use nothing or `console.error` for caught failures.
- Transcript source: InnerTube `POST https://www.youtube.com/youtubei/v1/get_transcript` with the page's own key/context; DOM panel fallback. Never the caption `baseUrl` path (verified dead 2026-10-25).
- "No transcript" is a normal state: no LLM call is made, all three panels show the same empty state, Generate and chat input disabled.
- Model catalogue (verified against provider docs 2026-10-25):
  - openai: `gpt-6-luna` (default), `gpt-6.1-sol`, `gpt-6-astra`; key URL `https://platform.openai.com/api-keys`
  - anthropic: `claude-haiku-5-5` (default), `claude-sonnet-5-5`, `claude-opus-5-5`; key URL `https://platform.claude.com/settings/keys`
  - google: `gemini-3.8-flash` (default), `gemini-3.5-flash-lite`, `gemini-3.1-pro-preview`; key URL `https://aistudio.google.com/apikey`
- Anthropic provider must be created with header `anthropic-dangerous-direct-browser-access: true` (requests from a service worker carry an Origin header).
- Transcript character budget in prompts: `TRANSCRIPT_CHAR_BUDGET = 120_000`. Truncation cuts at a line boundary and appends `[Transcript truncated]`.
- Transcript panel blocks: merge consecutive segments until a block spans at least `12_000` ms.
- Chat history cap: `MAX_STORED_CHATS = 20` videos, evict oldest `updatedAt`.
- Sizing inside the shadow root: all `rem` in built CSS converted to `px` at a `14px` base by an inline PostCSS plugin. Theme variables declared on `:root, :host`. Dark mode via `.dark` class on the app wrapper (`@custom-variant dark (&:where(.dark, .dark *))`).
- Every Radix/Base UI portal (Select, Tooltip, Dropdown, Popover) renders into the shadow-root container from `PortalContainerContext`, never `document.body`.
- Keyboard: manifest command `toggle-panel`, suggested key `Alt+Shift+Y`.
- Biome is the only linter/formatter: 2-space indent, double quotes, semicolons `asNeeded`, line width 100.
- Commit after every task with a conventional-commit message ending in `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. Captions exist only in a non-English language (e.g. a Japanese-only manual track): the transcript must load, non-Latin text must survive parsing, and the language label must show. Pinned in Task 4 (`parseGetTranscriptResponse` with a non-Latin fixture) and Task 5 (`pickCaptionTrack`).
2. Multi-hour video: the prompt must be truncated at a line boundary with a notice, never cut mid-segment, and never exceed the budget. Pinned in Task 6.
3. Navigating from a watch page to the home page and back to a different video: the panel must detect "no video" and the new id, and must not keep the old transcript. Pinned in Task 5 (`getVideoIdFromUrl`, `onVideoChange`).
4. Timestamp-looking text that is not a timestamp (`16:9`, `2024:`, `3:75`, text inside code spans or existing links): must not become seek links; valid `1:02:03` must. Pinned in Task 2.
5. Key revoked or wrong, or the service worker port drops mid-stream: the UI must show a readable error and stop spinning, never hang. Pinned in Task 8 (`mapStreamError`) and Task 9 (`openStream` on disconnect).
